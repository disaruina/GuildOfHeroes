## ответы на вопросы второй лабораторной по ООП
1. Почему при yaroslav.TakeDamage(25); не меняется здоровье Артёма и куда попадает 25?
Здоровье у Артема не меняется меняется здоровье у другого героя Ярослав т.к. метод применяется к ярославу. число 25 попадет в метод TakeDamage где проходит проверку и убирает хп у героя 
2. Чем отличаются return; в TakeDamage и return Health > 0; в IsAlive?
Return в TakeDamage просто останавливает работу метода а точнее выход из метода а уже return Health > 0; в IsAlive возвращает ответ метода
3. Как получить строку о герое, не печатая её сразу? Какая строка программы печатает её позже?
Сохранить вызов метода GetInfo() в переменную а потом просто ее вывести через WriteLine

4. Какие пять методов появились; как проверили недопустимый урон; какие итоговые здоровье и опыт получили.
**Пять новых методов:** `TakeDamage` `Heal` `GainExperience` `IsAlive` `GetInfo`
**Проверка недопустимого урона:** Отрицательный урон просто проверили в методе и вышли через `return;`. Слишком сильный урон сбросил здоровье Артёма до 0 благодаря проверке нижней границы.
**Итоговые показатели героев:**
  * Ярослав: Здоровье = 85 Опыт = 65 (Жив)
  * Анастасия: Здоровье = 60 Опыт = 0 (Жива)
  * Артём: Здоровье = 0 Опыт = 0 (Мертв)
